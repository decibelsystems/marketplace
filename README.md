# Decibel Systems Marketplace

Plugin marketplace for the Decibel ecosystem on Claude Code.

## Installation

```bash
/plugin marketplace add decibelsystems/marketplace
```

## Available Plugins

| Plugin | Description |
|--------|-------------|
| **homebase** | Branch identity, conventions, and plugin protocol |
| **peers** | Peer network patterns: specialist personas, discovery, handoff protocols |
| **superpowers** | Superpowers remix with sentinel-powered project tracking and reduced ceremony |

## Install individual plugins

```bash
/plugin install homebase@decibelsystems
/plugin install peers@decibelsystems
/plugin install superpowers@decibelsystems
```

All plugins are independent and composable. Install any combination.

## Philosophy

- **Homebase** gives a branch its shape
- **Peers** gives it specialist coordination
- **Superpowers** gives it optional workflow juice
- **Marketplace** makes it discoverable
